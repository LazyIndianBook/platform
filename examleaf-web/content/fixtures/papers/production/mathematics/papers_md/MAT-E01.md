**1. Answer the following as directed (any ten) :** &nbsp; `1×10=10`

(a) Let $A = \{1, 2\}$. Write the total number of relations that can be defined from $A$ to $A$. **[1]**

(b) A function $f : X \to Y$ is one-one (or injective) if the images of distinct elements of $X$ under $f$ are always ________. **(Fill in the blank)** **[1]**

(c) If $A$ and $B$ are invertible matrices of the same order, then $(AB)^{-1}$ is (Choose the correct answer)  **[1]**

(i) $A^{-1}B^{-1}$ &nbsp;&nbsp; (ii) $BA$ &nbsp;&nbsp; (iii) $AB$ &nbsp;&nbsp; (iv) $B^{-1}A^{-1}$

(d) Write the order of the matrix $A = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{bmatrix}$.  **[1]**

(e) State True or False : The function $f(x) = \lvert x - 3\rvert$ is differentiable at $x = 3$. **[1]**

(f) $\dfrac{d}{dx}\left(e^{3x}\right)$ at $x = 0$ is (Choose the correct answer) **[1]**

(i) 1 &nbsp;&nbsp; (ii) 3 &nbsp;&nbsp; (iii) $e^3$ &nbsp;&nbsp; (iv) 0

(g) If $y=\dfrac{x^2}{(x+1)^3}$, $x>0$, write $\dfrac{1}{y}\dfrac{dy}{dx}$. **[1]**

(h) The function $f(x) = x^2$ is strictly decreasing on the interval ________. (Fill in the blank) **[1]**

(i) Evaluate: $\displaystyle\int \dfrac{dx}{x^{2}+16}$. **[1]**

(j) The order of the differential equation $\dfrac{d^4y}{dx^4}-y=0$ is (Choose the correct answer) **[1]**

(i) 1 &nbsp;&nbsp; (ii) 4 &nbsp;&nbsp; (iii) 3 &nbsp;&nbsp; (iv) 2

(k) State True or False : The vector $-\vec a$ has the same direction as $\vec a$. **[1]**

(l) The angle between the two lines whose direction cosines are $\left(\dfrac12,\dfrac12,\dfrac1{\sqrt2}\right)$ and $\left(\dfrac12,\dfrac12,-\dfrac1{\sqrt2}\right)$ is (Choose the correct answer). **[1]**

(i) $30^\circ$ &nbsp;&nbsp; (ii) $45^\circ$ &nbsp;&nbsp; (iii) $90^\circ$ &nbsp;&nbsp; (iv) $60^\circ$
