**1. Answer the following as directed (any ten) :** &nbsp; `1×10=10`

(a) If $A = \{a,b,c\}$ and $B = \{1,2\}$, find the total number of relations from the set $A$ to the set $B$. **[1]**

(b) The number of one-one functions from a set with $2$ elements to a set with $2$ elements is ________. **(Fill in the blank)** **[1]**

(c) If a square matrix $A$ satisfies $A^2 = I$, then $A^{-1}$ is (Choose the correct answer)  **[1]**

(i) $I$ &nbsp;&nbsp; (ii) $-A$ &nbsp;&nbsp; (iii) $A$ &nbsp;&nbsp; (iv) $A'$

(d) Construct a $2\times1$ matrix $A = [a_{ij}]$ whose elements are given by $a_{ij} = (i+j)^2$.  **[1]**

(e) State True or False : The function $f(x) = \lvert x\rvert$ is not differentiable at $x=0$, although it is continuous there. **[1]**

(f) $\dfrac{d}{dx}\left(e^{x^2}\right)$ at $x=1$ is (Choose the correct answer) **[1]**

(i) $e$ &nbsp;&nbsp; (ii) $2$ &nbsp;&nbsp; (iii) $e^2$ &nbsp;&nbsp; (iv) $2e$

(g) If $y=\sqrt{\dfrac{x-1}{x+1}}$, $x>1$, write $\dfrac{1}{y}\dfrac{dy}{dx}$. **[1]**

(h) The function $f(x) = x^3 - 3x^2 + 3x + 2$ is ________ on $\mathbf{R}$, since $f'(x) = 3(x-1)^2 \geq 0$ for all $x$. (Fill in the blank) **[1]**

(i) Evaluate: $\displaystyle\int \dfrac{dx}{\sqrt{4-x^2}}$. **[1]**

(j) The order of the differential equation $\dfrac{d^4y}{dx^4}+\left(\dfrac{d^2y}{dx^2}\right)^2=0$ is (Choose the correct answer) **[1]**

(i) 4 &nbsp;&nbsp; (ii) 3 &nbsp;&nbsp; (iii) 2 &nbsp;&nbsp; (iv) 5

(k) State True or False : The vectors $2\hat i+3\hat j-\hat k$ and $-6\hat i-9\hat j+3\hat k$ are collinear. **[1]**

(l) The angle between the lines with direction ratios $1,2,1$ and $2,1,-1$ is (Choose the correct answer). **[1]**

(i) $60^\circ$ &nbsp;&nbsp; (ii) $45^\circ$ &nbsp;&nbsp; (iii) $30^\circ$ &nbsp;&nbsp; (iv) $90^\circ$
